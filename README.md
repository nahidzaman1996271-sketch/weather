# 🌦️ Weather Dashboard

A sleek, dark-themed weather dashboard that delivers real-time conditions and forecasts for any city in the world — clean UI, live data, zero clutter.

🔗 **Live Demo:** [nahidzaman1996271-sketch.github.io/weather](https://nahidzaman1996271-sketch.github.io/weather/)

---

## ✨ Features

- 🔍 **City Search** — instantly look up current weather for any city worldwide
- 🌡️ **Live Conditions** — real-time temperature, "feels like," and sky summary
- 💧 **Detailed Metrics** — humidity, wind speed, atmospheric pressure, and visibility
- 🌅 **Sun & Moon Tracker** — sunrise/sunset times with a visual day-progress arc
- 📅 **5-Day Forecast** — upcoming highs/lows and precipitation chances
- ☁️ **Live Sky Panel** — dedicated section for current sky conditions
- 🕒 **Real-Time Clock** — local time and date synced to the searched location

## 🚀 Getting Started

Clone the repo and open it locally — no build step required:

```bash
git clone https://github.com/nahidzaman1996271-sketch/weather.git
cd weather
```

Then simply open `index.html` in your browser.

### API Key Setup

This project fetches live data from a weather API. If you're running your own copy:

1. Get a free API key from your weather data provider
2. Add your key inside `script.js`
3. Reload the page and search any city
